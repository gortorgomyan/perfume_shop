# L ESSENCE — Luxury Perfume E-commerce

Static site: HTML, CSS, JavaScript only.

## Open the site

Double-click `index.html` or run: `npx serve .` inside this folder.

## Pages

- index.html — Home
- shop.html — Catalog with filters
- product.html — Aura product page
- checkout.html — Cart and checkout
